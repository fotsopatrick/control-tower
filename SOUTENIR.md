# Soutenir Control Tower

Control Tower est developpe par une seule personne, sur son temps libre, et
publie sous licence Apache 2.0 : vous pouvez l'utiliser, le modifier et le
distribuer, y compris dans une entreprise.

## Ce que le projet coute vraiment

Il ne coute pas rien. Ce qui le fait tourner, chaque mois :

- un serveur qui heberge la demonstration et les services,
- un nom de domaine,
- l'acces aux modeles de langage utilises pour les essais.

Ces lignes sont payees par l'auteur. Un don ne paie pas un salaire : il paie
la machine, pour que la demonstration reste allumee et que le projet continue.

## Comment aider, du plus utile au moins utile

1. **Utilisez-le, et dites ce qui casse.** Un rapport precis vaut mieux qu'un
   don : il fait avancer le code.
2. **Racontez-le.** Une mention quelque part amene un utilisateur, et un
   utilisateur amene un contributeur.
3. **Contribuez.** Les entrees faciles sont listees dans les tickets.
4. **Donnez.** Le lien est sur la page du projet.

## Ce que le projet ne fera pas

Il ne deviendra pas payant en cachant une partie du code. Ce qui est publie
ici reste publie sous Apache 2.0.
